RESUMECRAFT — HTML / CSS / JAVASCRIPT RESUME BUILDER

FILES
- index.html       Main website
- style.css        Layout, responsive styling, and print styles
- script.js        Resume form, live preview, templates, and local saving
- assets/          Local SVG logo and template preview images

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it in Chrome, Edge, or Firefox.
4. Fill in your details. The preview updates as you type.
5. Choose Modern, Classic, or Minimal from the template selector.
6. Click "Save as PDF". In the print dialog choose "Save as PDF" or select your printer.

FEATURES
- Personal details, professional summary, experience, education, skills, projects,
  certifications, and languages.
- Add and remove multiple experience and education entries.
- Three resume templates.
- Automatic browser LocalStorage saving on the same browser/device.
- Responsive editor and A4 print layout.
- No backend and no account required.

NOTES
- Uses only HTML, CSS, and vanilla JavaScript for application logic.
- Google Fonts are loaded from Google Fonts when internet is available; system fonts
  remain as fallback.
- Your resume information is stored locally in your browser using LocalStorage.
- PDF export uses the browser's print dialog. For best results choose A4 paper,
  scale 100%, and disable browser headers/footers if that option is shown.
